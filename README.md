# 🎮 Tic Tac Toe Game

A simple and interactive **Tic Tac Toe game** built with **HTML, CSS, and JavaScript**.  
Players take turns marking spaces on a 3×3 grid, and the game automatically detects winners or draws.  
Includes a **scoreboard** to track Human vs Computer wins.

---

## ✨ Features
- 🎨 Clean and responsive UI
- 🏆 Winner detection with predefined win patterns
- 📊 Scoreboard tracking Human and Computer scores
- 🔄 Reset and New Game functionality
- ⚡ Interactive hover effects for a playful experience

---

This project is perfect for practicing DOM manipulation, event handling, and game logic in JavaScript.
